Overview

GitHub Analytics Pro provides a RESTful API to access comprehensive GitHub user analytics, repository statistics, and advanced metrics.

Base URL
{{ request.url_root }}api

Authentication

Currently, the API does not require authentication for public access. However, rate limiting is applied per IP address.

API Endpoints

GET /api/user/{username}

Get comprehensive statistics for a GitHub user.

Parameters
Name Type Description
username string GitHub username (path parameter)
Example Request
GET {{ request.url_root }}api/user/octocat
Example Response
{
  "user": {
    "name": "The Octocat",
    "login": "octocat",
    "bio": "GitHub's mascot",
    "followers": 1000,
    ...
  },
  "stats": {
    "public_repos": 50,
    "total_stars": 5000,
    ...
  },
  "advanced_metrics": {
    "impact_score": 85.5,
    ...
  }
}
GET /api/user/{username}/history

Get historical analytics snapshots for a user.

Parameters
Name Type Description
username string GitHub username (path parameter)
days integer Number of days of history (default: 90, max: 365)
Example Request
GET {{ request.url_root }}api/user/octocat/history?days=30
POST /api/compare

Compare multiple GitHub users.

Request Body
{
  "usernames": ["octocat", "torvalds", "gvanrossum"]
}
Example Request
POST {{ request.url_root }}api/compare
Content-Type: application/json

{
  "usernames": ["octocat", "torvalds"]
}
GET /api/search/users

Search for GitHub users.

Parameters
Name Type Description
q string Search query
Example Request
GET {{ request.url_root }}api/search/users?q=octocat
GET /api/rate-limit

Get current GitHub API rate limit status.

Example Request
GET {{ request.url_root }}api/rate-limit

Rate Limiting

API requests are rate-limited to prevent abuse:

  • /api/user/* - 30 requests per minute
  • /api/compare - 10 requests per minute
  • /api/search/* - 20 requests per minute
  • /export/* - 10 requests per minute

Rate limits are applied per IP address. If exceeded, you'll receive a 429 status code.

Code Examples

JavaScript (Fetch API)
// Get user stats
fetch('{{ request.url_root }}api/user/octocat')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
Python (Requests)
import requests

# Get user stats
response = requests.get('{{ request.url_root }}api/user/octocat')
data = response.json()
print(data)
cURL
# Get user stats
curl {{ request.url_root }}api/user/octocat

# Compare users
curl -X POST {{ request.url_root }}api/compare \
  -H "Content-Type: application/json" \
  -d '{"usernames": ["octocat", "torvalds"]}'
